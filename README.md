# Shadowrocket lists from itdoginfo/allow-domains

Rule sets for Shadowrocket, auto-converted from https://github.com/itdoginfo/allow-domains
every 6 hours by GitHub Actions.

Import in Shadowrocket: Config → + → paste
`https://raw.githubusercontent.com/kostiashkaaa/shadowrocket-lists/main/rules/shadowrocket.conf`

Single rule sets: `rules/*.list`, `rules/services/*.list`, `rules/categories/*.list`
(use as `RULE-SET,<raw url>,PROXY`).
